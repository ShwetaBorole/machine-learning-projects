This project applies machine learning techniques to smart meter energy data to:

--Detect unusual or abnormal energy usage patterns (anomaly detection)

--Forecast short-term electricity consumption (load forecasting)

The goal is to simulate real-world utility and smart grid analytics and working with time-series sensor data such as power, voltage, and current.

Problem Statement

Modern smart grids generate large volumes of time-series data from meters and sensors. Manually monitoring this data is not scalable.

This project answers two key questions:

Is the energy usage normal or abnormal? Anomaly detection

How much power will be consumed in the near future?

Dataset

Source: UCI Household Electric Power Consumption Dataset

Data Type: Time-series (1-minute resolution)
